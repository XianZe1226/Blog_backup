# 喜提索尼 A7M5 和适马 24-70 f/2.8 二代

等了大半年，这套机器总算到手了。

---

## 机身：索尼 Alpha 7 V（A7M5）

索尼在 2025 年 12 月发布的 **Alpha 7 V（型号 ILCE-7M5）**，是 A7 系列的第五代机身。型号里的 "V" 是罗马数字 5，官方中文叫"阿尔法 7 V"，我下面还是按习惯写成 A7M5。

### 影像核心

| 参数 | 规格 |
|------|------|
| 传感器 | 35mm 全画幅 (35.9×23.9mm) 部分堆栈式 Exmor RS CMOS |
| 有效像素 | 约 **3,300 万像素** (总像素约 3,570 万) |
| 影像处理器 | **BIONZ XR2** (内置 AI 处理单元) |
| 动态范围 | 最高 **16 级** |
| 感光度范围 | ISO 100–51200 |
| 色温范围 | 2500K–9900K |

3300 万像素是我比较喜欢的档位：裁切空间比 2400 万像素宽松不少，单张文件又没到 6000 万像素那么夸张，后期修起来压力小。

### 对焦系统

| 参数 | 规格 |
|------|------|
| 对焦点 | **759 个相位检测对焦点**，覆盖约 **94%** 画面 |
| 最低对焦照度 | **EV -4.0** |
| AI 识别主体 | 人 / 动物 / 鸟类 / 昆虫 / 汽车 / 火车 / 飞机（**7 种**） |
| AF/AE 计算 | 高达 **60 次/秒** |
| AI 识别 AF 提升 | 较上一代提升约 **30%** |

这代的升级重点基本都在对焦上。759 个对焦点几乎铺满整个画面，构图时不用老想着把主体往中间区域挪。实际用下来眼部追焦很稳，拍跑动的小孩或者飞鸟，脱焦的次数比上一代明显少。

### 连拍

| 参数 | 规格 |
|------|------|
| 最高连拍速度 | **30 张/秒**（电子快门，无黑屏，带 AF/AE 追踪） |
| RAW 格式连拍 | 支持 **14-bit RAW** 30 张/秒 |
| 预拍摄功能 | 可记录按下快门前最长 **1 秒** 的影像 |
| 最高快门速度 | **1/16000s**（电子快门） |
| 读取速度 | 较上代提升约 **4.5 倍** |

30 张/秒在几年前还是旗舰机的规格，现在下放到了 A7 这条线。对我更有用的是预拍摄：按下快门前 1 秒的画面会一起存下来，拍鸟起飞、小孩跳水这类时机难抓的场景，容错率高了很多。

### 视频

| 参数 | 规格 |
|------|------|
| 全画幅 4K | **7K 超采样 → 4K 60p**（全像素读取，无裁切） |
| Super 35mm 模式 | **4K 120p** / HD 240p |
| 防抖增强 | 新增 **Dynamic Active Mode** 动态防抖增强 |
| AI 自动构图 | 自动维持最佳构图 |
| 其他功能 | 自定义 LUT 导入、Shot Mark 帧标记、缩时摄影、机内降噪麦克风 |

7K 超采样到 4K 60p 是这代视频部分最实在的一项，全画幅下不用裁切就能拿到 4K 60p，还带 10-bit 和 S-Log。4K 120p 只在 Super 35mm 模式下可用，会损失一点视角，慢动作需求多的话要提前算好焦段。自定义 LUT 导入和 Shot Mark 是两台机器上都有的功能，干活时挺省事。

### 取景与屏幕

| 参数 | 规格 |
|------|------|
| 显示屏 | **3.2 英寸 210 万像素** 4 轴多角度翻转触摸屏 |
| 电子取景器 | 0.5 英寸 Quad-VGA OLED，**3,686,400 点** |
| 取景器放大倍率 | 约 **0.78×** |
| 取景器刷新率 | STD 60fps / 高 **120fps** |
| 竖屏菜单 | ✅ 支持 |

四轴翻转屏比上一代的三向翻转灵活，横拍竖拍都能翻到合适角度，竖屏时菜单也会跟着转。EVF 是 369 万点、0.78× 放大倍率，120fps 刷新率下取景拖影很少。

### 防抖

| 参数 | 规格 |
|------|------|
| 防抖类型 | **5 轴光学机身防抖** |
| 中央补偿 | 最高 **7.5 级** |
| 边缘补偿 | 最高 **6.5 级** |

7.5 级是 CIPA 标准下的实验室数据，实际能不能手持 1 秒不虚，还是要看姿势和焦段，我自己大概到 1/4 秒比较有把握。夜景拍摄基本可以不带三脚架了，这点提升最直观。

### 连接与存储

| 参数 | 规格 |
|------|------|
| USB 接口 | **双 USB Type-C** |
| HDMI | **全尺寸 HDMI** |
| 无线 | **Wi-Fi 6E** (5GHz) + 蓝牙 |
| 卡槽 1 | CFexpress Type A / SD (UHS-II) |
| 卡槽 2 | SD (UHS-II) |
| 音频 | 麦克风 + 耳机 + 数字音频热靴 |

双 Type-C 可以一边充电一边传素材，全尺寸 HDMI 接监视器不用再找转接头。CFexpress Type A 卡槽保证了 30 张/秒连拍和 4K 120p 的写入速度，双卡槽也能设成同时记录，手里踏实一些。

### 续航与机身

| 参数 | 规格 |
|------|------|
| 电池 | NP-FZ100 (2280mAh) |
| 照片续航 | LCD 约 **750 张** / EVF 约 **630 张** |
| 机身材质 | **全镁合金框架**（顶盖、前盖、内框、后盖） |
| 颜色 | 经典黑 |
| 产地 | 中国无锡 |

全镁合金框架，握持手感很扎实。750 张的续航按我平时的拍法，出门一天基本用不完一块电池。散热也比上一代好，4K 60p 连续录了一个多小时没出现过热提示。

## 镜头：适马 24-70mm f/2.8 DG DN II | Art

再说这颗一起买的挂机头。适马在 2024 年 5 月发布的第二代大三元标变——**24-70mm F2.8 DG DN II | Art（A024）**，一代上被吐槽的地方基本都改了。

### 光学结构

| 参数 | 规格 |
|------|------|
| 镜头结构 | **15 组 19 片** |
| 特殊镜片 | **6 片 FLD** 萤石级低色散镜片 + **2 片 SLD** 特殊低色散镜片 + **5 片非球面镜片** |
| 光圈叶片 | **11 片**（圆形光圈） |
| 最大光圈 | **F2.8 恒定** |
| 最小光圈 | F22 |
| 滤镜尺寸 | **φ82mm** |
| 镀膜 | 纳米多孔镀膜（NPC）+ 超级多层镀膜 |

6 片 FLD 加 2 片 SLD、5 片非球面，用料比一代更足。实拍下来中心锐度没什么可挑的，F2.8 全开就够用，边缘收一档光圈会更好。11 片圆形光圈，光斑形状比较规整。24-70 这个焦段配 F2.8 恒定光圈，出门带这一颗基本能应付大多数场景。

### 对焦与近摄

| 参数 | 规格 |
|------|------|
| 对焦马达 | **HLA 高速线性马达**（High-response Linear Actuator） |
| 对焦速度 | 相比一代提升约 **3 倍** |
| 最近对焦距离 | **17cm**（24mm 广角端）/ 34cm（70mm 长焦端） |
| 最大放大倍率 | **1:2.7**（24mm 端）|
| 呼吸效应 | ✅ 显著抑制，视频友好 |

HLA 线性马达对焦又快又安静，配 A7M5 的机身对焦基本是即按即合。最近对焦距离 17cm，拍美食、花草特写很方便，日常当中焦微距用没问题。呼吸效应抑制得不错，视频里切焦点时画面不会明显伸缩。

### 尺寸与重量

| 参数 | 规格 |
|------|------|
| 直径 | φ87.8mm |
| 长度 | 122.2mm（E 卡口） |
| 重量 | 仅 **735g**（E 卡口，比一代轻 10%） |

735g 比一代轻了将近 10%，长度也短了一些，但光学素质反而更好。这颗头挂机一天下来，负担比我原来那颗轻不少。

### 操控

| 功能 | 说明 |
|------|------|
| **光圈环** | ✅ 新增！带无级切换 & 锁定开关 |
| **AFL 按钮** | **2 个**（侧面 + 顶部） |
| **变焦锁定开关** | ✅ 防止镜筒意外伸出 |
| **防尘防溅** | ✅ 全结构密封 |
| **防水防油涂层** | ✅ 前镜片 |
| **遮光罩** | LH878-05 花瓣形带锁遮光罩 |

新增的光圈环是二代最实用的改动，有刻度也能切到无级，拍视频时过渡很顺。两个 AFL 按钮横拍竖拍都够得着。镜身做了全密封，前镜片还有防水防油涂层，遇到小雨不用急着收机器。

## 一些实际使用感受

装上机身的第一感觉是重量分布很舒服。整套拿在手里比我原来那套轻了一截，背一天肩膀没那么酸。

对焦是最明显的提升。在室内光线一般的情况下对着家里的猫拍，AI 眼部识别能一直咬住眼睛不放，30 张/秒连拍按下去，回看基本张张合焦。

高感表现也够用，ISO 6400 下画面还算干净，配上机身防抖，晚上扫街出片率不错。3300 万像素的裁切余量比较大，二次构图很自由。

视频方面，7K 超采样到 4K 60p 的细节和色彩都挺讨喜，直出就能用。Dynamic Active Mode 打开后手持走拍的抖动明显减弱，日常拍 Vlog 够用了。

---

## 总结

A7M5 加适马 24-70 II，这一套拍照和视频都能兼顾：对焦可靠、连拍够快、4K 60p 不裁切、镜头轻便，是我目前比较满意的搭配。

接下来就是带着它多出去拍点东西了。
